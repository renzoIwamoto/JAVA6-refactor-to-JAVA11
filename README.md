# JAVA6-refactor-to-JAVA11
Test LLMs to refactor JAVA 6 project to JAVA 21 and generate unit tests

## Prompt para generar código en JAVA 6
Necesito que generes un proyecto Maven en Java 6.
  Este proyecto será usado para probar herramientas de IA que 
  refactorizan código antiguo a Java 21, así que debe estar 
  estrictamente limitado a APIs de Java 6 y no usar 
  características modernas. Has el proyecto completo y genera 
  un readme para explicar las dependencias necesarias y como 
  ejecutarlo
